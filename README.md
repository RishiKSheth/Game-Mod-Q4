Do you like Quake 4 unironcally? 

This is the mod called GhostQuakers. 

How to play 

Movement: 
Added backdash for character by clicking the s key 

Added left and right dash for character by clicking a and d key

Added Super jump feature (space key) 

Flying (Space Key + W key)

Weapons: 

Napalm Gun: Added Bounce to Bullets 

Rocket Launcher: Completely Useless Ninjas don't use Rocket Launchers! Shoots 10 rockets but doesn't do any damage

Machine Gun: Made into a sniper 

Lightning Gun: Don't play with this one 

Grenade Launcher: Increased reloadtime, bounceyness, and the number of grenades that come out 

Shotgun: increased number of hits while decreasing damage

Rail Gun, Increased the # of bullets, whilst increasing the reload time

Nail Gun: Added more bullets and now can bounce all over the place

Dark Matter Gun: Increased number of hits 

Hyperblaster: Decreased Damage, increased # of hits, Bounceyness
